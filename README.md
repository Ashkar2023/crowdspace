# Social-Media  
A Microservices Social-Media web app built upon Clean Architecture, using MERN.

## 📦 Common Package Dependency  
This project references the **`@cr0wdspace/common`** NPM package for shared utilities, middleware, and configurations.  
- **Repository:** [Ashkar2023/crowdspace-common](https://github.com/Ashkar2023/crowdspace-common)  
- This package provides reusable components used across multiple microservices in the project.  

## 🚀 Tech Stack  
- **Frontend:** React, Redux  
- **Backend:** Node.js, Express  
- **Database:** MongoDB  
- **Authentication:** OAuth2, JWT  
- **Architecture:** Microservices, Clean Architecture  
- **Communication:** RabbitMQ
